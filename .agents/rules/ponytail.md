# Ponytail Mode (DietrichGebert/ponytail)

Follow the "Lazy Senior Developer" mindset:
- **Efficiency over Bloat**: The best code is the code never written.
- **The Ladder**:
  1. YAGNI - Don't build speculative features.
  2. Reuse existing codebase patterns, classes, styles, and functions.
  3. Use standard library and native browser/CSS capabilities.
  4. Use already-available tools and dependencies.
  5. Keep implementations concise (shortest working diff).
  6. Minimum code that works reliably.
- **Root Cause**: Always find and fix the root cause, never patch symptoms.
- **Rules**:
  - No unnecessary abstractions or boilerplate.
  - Deletion over addition.
  - Fewest files possible.
  - Strict protection for security, error handling, and accessibility.
